# Sorting App

Консольное приложение на Java 21 для сортировки коллекции автомобилей. Поддерживает несколько алгоритмов сортировки, три способа ввода данных и работает в непрерывном цикле до явного выхода пользователя.

## Возможности

**Алгоритмы сортировки** — реализованы через паттерн Стратегия:
- Сортировка вставками
- Сортировка слиянием
- Сортировка по чётным значениям поля (чётные сортируются, нечётные остаются на месте)

**Поля для сортировки:** мощность, модель, год производства

**Способы заполнения коллекции:**
- Ручной ввод
- Загрузка из файла
- Случайная генерация

**Дополнительно:**
- Запись отсортированных коллекций в файл в режиме добавления
- Многопоточный подсчёт вхождений элемента в коллекцию
- Кастомная коллекция на основе динамического массива

## Структура проекта

```
src/main/java/com/aston/sorting/
├── model/          — класс Car и Builder
├── strategy/       — интерфейс и реализации алгоритмов сортировки
├── comparator/     — компараторы по трём полям
├── io/
│   ├── input/      — ручной ввод, файл, рандом
│   └── output/     — запись результатов в файл
├── validation/     — валидация входных данных
├── collection/     — кастомная коллекция
├── concurrent/     — многопоточный подсчёт вхождений
└── app/            — главный цикл, консольное меню
```
