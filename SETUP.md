# Настройка окружения

## Требования

Перед началом работы убедись, что на твоём компьютере установлено следующее:

- **Java 21**
- **Maven 3.9+**
- **Git**

Проверить установку можно в терминале:

```
java -version
mvn -version
git --version
```

Если всё установлено корректно, ты увидишь примерно следующее:

```
java version "21.0.x" ...
Apache Maven 3.9.x ...
git version 2.x.x
```

> Если используешь VS Code — убедись, что установлен **Extension Pack for Java**, иначе Maven и Java могут не определиться корректно.

## Установка Maven

### Windows

1. Перейди на [maven.apache.org](https://maven.apache.org/download.cgi) и скачай бинарный архив `apache-maven-3.9.x-bin.zip`
2. Распакуй архив, например в `C:\Program Files\Maven`
3. Добавь Maven в переменные окружения:
   - Открой **Пуск → Переменные среды** (или найди через поиск "переменные среды")
   - В разделе **Системные переменные** создай новую переменную:
     - Имя: `MAVEN_HOME`
     - Значение: `C:\Program Files\Maven\apache-maven-3.9.x`
   - Найди переменную `Path`, нажми **Изменить** и добавь: `%MAVEN_HOME%\bin`
4. Открой новый терминал и проверь: `mvn -version`

### macOS

Самый простой способ — через Homebrew:

```
brew install maven
```

Проверить: `mvn -version`

## Клонирование репозитория

```
git clone https://github.com/al3xStark/ASTON-TEAM-PROJECT.git
cd ASTON-TEAM-PROJECT
git checkout develop
```

> Важно: после клонирования ты окажешься на ветке `main`. Переключись на `develop` — именно отсюда начинается вся работа.

---

## Сборка проекта

```
mvn clean install
```

Maven скачает все зависимости, скомпилирует код и прогонит тесты. Первый раз может занять несколько минут — это нормально.

Если всё прошло успешно, в конце вывода увидишь:

```
BUILD SUCCESS
```

---

## Запуск тестов

```
mvn test
```

Прогоняет все тесты проекта. В конце вывода:

- `BUILD SUCCESS` — все тесты прошли
- `BUILD FAILURE` — один или несколько тестов упали, смотри вывод выше — там будет указано какой тест и почему

---

## Частые проблемы

**`JAVA_HOME` не установлен (чаще всего на Windows)**

Maven не может найти Java. Нужно прописать переменную окружения:
- Имя: `JAVA_HOME`
- Значение: путь к папке с JDK, например `C:\Program Files\Java\jdk-21`

Затем добавь `%JAVA_HOME%\bin` в переменную `Path`.

---

**Проект не компилируется после `git pull`**

Попробуй пересобрать с нуля:

```
mvn clean install
```

---

**Тесты падают и мешают сборке**

Временный костыль — пропустить тесты при сборке:

```
mvn install -DskipTests
```

Это способ разобраться с остальным кодом, пока тест сломан. Починить тест всё равно нужно.
